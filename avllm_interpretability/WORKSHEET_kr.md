## 후속 활동 — 3·4·7·8

각 활동에서 한 비교를 정합니다. **프롬프트나 클립을 바꾸면 기준 캡션이 새로 생성**됩니다. 같은 클립·프롬프트·상한에서 target이나 레이어만 바꾸면 같은 캡션을 재사용합니다. 실제 기록에서 이를 확인하세요.

| 우선순위 | 바꿀 것 | 고정할 것 | 실행 전 가설 | 비교한 실행 ID | 관측값·경쟁 설명 |
|---|---|---|---|---|---|
| **3 · 질문 초점** | 소리 → 보이는 내용 / 둘 다 / 직접 작성 | 클립·target·레이어·상한·8프레임 | | | |
| **4 · 레이어 대역** | 전체 / 초반 / 중반 / 후반 | 클립·프롬프트·target·상한·8프레임 | | | |
| **7 · 새 클립** | 업로드한 새 장면 | 프롬프트·target·레이어·상한·8프레임 | | | |
| **8 · 고급 경로** | `query_text` 또는 교차 모달·복합 규칙 | 클립·프롬프트·레이어·측정 종류·8프레임 | | | |

- **3:** 같은 언어에서 질문의 과제를 바꾼 효과와, 다른 캡션을 채점한 효과를 어떻게 구분할까? __________
- **4:** 선택한 대역: __________. 초반·중반·후반은 각 12개 레이어다. 전체 대역은 차단 수가 더 많다는 점을 어떻게 해석에 반영했는가? __________
- **7:** 새 영상의 소리·장면: __________. 비교 영상에서 유지한 조건과 바뀐 조건: __________. 임의 업로드에는 자동 대조 연결이 없으므로 대응 ID와 대조 근거를 직접 적는다: __________
- **8:** 측정 종류(TF 캡션 확률 / logit-lens 문자열 다양성): __________. 정확한 규칙: __________. 복합 차단이라면 각 단일 차단의 실행 ID: __________. 두 지표나 복합 효과를 혼동하지 않았는가? __________

생성 상한은 캡션 잘림을 복구할 때만 조정합니다. 상한을 바꿨다면 비교 실행을 같은 상한으로 다시 만들고 위 표의 ID를 갱신하세요. 언어 변경은 프롬프트 셀의 선택적 주석 안내이며 별도 영어 실험은 제출 필수가 아닙니다.

## 근거와 제출

판정은 **지지 / 반증 / 판단 유보** 중 선택하고 이유를 적습니다. 표에 다 담기지 않는 전체 캡션과 토큰별 결과도 함께 제출합니다.

- 이 관측의 **경쟁 설명**은 무엇인가? (간접 경로, 정보 중복, 캡션 내용·잘림, 토큰화, 측정 민감도 등) __________
- 경쟁 설명을 구분하는 다음 실험에서 바꿀 **한 변수**는 무엇인가? __________
- 결과가 말해 주지 않는 것은 무엇인가? __________

**제출 확인:** 8프레임을 유지했는가? 비교 설정과 실행 ID를 남겼는가? 같은 캡션 비교와 캡션이 달라진 비교를 구분했는가? 전체 캡션·상한·판정을 보관했는가? 결과 파일이 실제로 열리는가? replay 결과와 새 실행을 구분했는가?

파일을 받지 못했다면 노트북의 JSON/Markdown 보기를 펼칩니다. 작은 기록은 전체 내용을 UTF-8 `lab_evidence.json`·`lab_log.md`로 저장합니다. 조각이 표시되면 각 **JSON 전체**를 같은 폴더에 `lab_evidence.json.part001.json`, `lab_evidence.json.part002.json` … 및 `lab_log.md.part001.json` …으로 저장합니다. 각 보기의 **“복사한 조각을 원본 파일로 복원하는 Python 코드”**를 그 폴더에서 실행해 원본 두 파일을 복원하세요. 필요하면 교사의 도움을 받습니다. 조각의 `text`만 따로 복사하거나 수정하지 말고, 순서·누락·SHA-256 검사를 통과한 최종 파일을 다시 열어 실행 ID·기록 수·캡션을 확인합니다.
