# 비전공자용 Molab 탐구 활동 설계

작성·검토일: 2026-10-08 (Asia/Seoul)  
기준 코드: `0d2eb6f7713a2c6e107b1fb3b54284f38eb1fe22`  
상태: 사용자 요구를 반영한 1차 검토본. 2026-10-08 후속 요청으로 새 영상의 10초 원본/무음 파일 준비를 완료했다. 노트북 기능 구현·새 GPU 검증·게시 전이다.

## 1. 목적과 학습 목표

비전공자 학생이 실제 수업용 `CTP49906_avllm_molab_html_kr.py`에서 영상을 보고 질문을 선택한 뒤, 조건을 바꿔 관찰하고 자기 설명의 한계를 점검하도록 한다. 드롭다운은 탐색의 출발점을 제공한다. 학생이 정해진 효과를 재현하는 것을 목표로 삼지 않는다.

첫 활동 뒤 학생은 다음을 자기 말로 설명할 수 있어야 한다.

1. 무엇을 바꾸고 무엇을 그대로 두었는가?
2. 실제 답변이나 수치에서 무엇이 달라졌는가? 같았다면 무엇이 같았는가?
3. 결과만으로 단정할 수 없는 것은 무엇이며, 다음에는 무엇을 확인하겠는가?

한국어판의 모든 추천 질문과 학습 활동은 한국어로 구성한다. 영어와의 성능·효과 비교는 학생 활동, 교사용 필수 절차, 후속 배포 약속에서 제외한다. 별도 영어판의 기존 기능 호환성 검사는 유지한다.

## 2. 첫 배포 범위

**활동 2종 × 영상 3종 × 한국어 질문 3종**을 기본 선택 범위로 제공한다. 기존 영상 1종에 새 영상 2종을 더한다. 각 영상은 원본·무음 한 쌍이므로 총 6개 파일이며, 새로 추가할 파일은 4개다. 기본 설정의 저장 비교 결과는 18개다. 학생에게 18개를 모두 실행하거나 제출하도록 요구하지 않는다.

### 활동 A: 소리를 없애면 설명이 달라질까?

- ID `sound_vs_silence`, 비교 종류 `input_condition`.
- 선택한 영상의 원본과 무음에서 각각 연결 차단 없이 캡션을 생성한다. 두 조건의 영상 프레임·프롬프트·모델·생성 설정은 동일하다.
- 기본값은 8프레임, 생성 상한 64토큰, 샘플링 없음이다. 새 GPU 검증을 거쳐 확정하며 상한 도달 여부를 표시한다.
- 서로 다른 두 답변을 나란히 보여 준다. 두 답변의 로그 확률을 직접 빼거나 자동 정답 판정을 하지 않는다.
- 무음에서도 소리를 언급했다면 화면의 단서·기존 지식 등 여러 설명을 검토한다. 이 한 번의 관찰로 특정 원인을 확정하지 않는다.

### 활동 B: 답변이 소리를 참조하는 연결을 막으면 어떻게 될까?

- ID `audio_edge_effect`, 비교 종류 `within_caption`.
- 원본 영상과 선택한 한국어 질문에서 캡션 C를 생성하고, **동일한 캡션 토큰 ID**를 기준선과 `answer→audio [0,36)`에서 채점한다. 기존 `teacher_forced_delta`를 사용한다.
- 오디오 입력은 유지되며, 지정한 어텐션 연결만 차단한다. 다른 경로로 전달된 정보가 남을 수 있으므로 이를 소리 정보의 완전한 제거로 설명하지 않는다.
- 같은 C에 대한 로그 확률 변화가 측정 대상이다. 새로운 차단 후 답변을 생성하는 활동이나 원본·무음 쌍으로 표시하지 않는다.
- 캡션과 변화 방향을 먼저 보여 준다. 합계 `nats`, 평균 `nats/token`, 모델 토큰별 값·특수 토큰은 세부 보기에 둔다. 효과 크기로 영상·질문·언어의 우열을 매기지 않는다.

### 한국어 질문 선택과 직접 탐색

| ID | 드롭다운 표시 | 모델에 전달할 정확한 문장 |
|---|---|---|
| `sound` | 소리 설명하기 | 영상에서 들리는 소리를 한 문장으로 설명해 주세요. |
| `visual` | 화면 설명하기 | 영상에 보이는 장면을 한 문장으로 설명해 주세요. |
| `combined` | 화면과 소리 함께 설명하기 | 영상에 보이는 장면과 들리는 소리를 함께 한 문장으로 설명해 주세요. |

- 첫 진입은 활동 A·기존 영상·`sound`로 시작한다. 질문을 바꾸는 것은 요청 문장의 변경이며 입력 모달리티를 제거하는 조작이 아니다. `visual`에서도 오디오가 입력된다.
- `직접 바꿔 보기`에서 질문 프리셋 또는 한국어 직접 입력, A의 4/8프레임, B의 레이어 구간을 제공한다. B는 전체·앞부분 `[0,12)`·중간 `[12,24)`·뒷부분 `[24,36)` 중 선택한다. 실제 레이어 수가 36이 아니면 B 실행을 거부한다.
- 직접 입력도 한글로 질문하도록 안내하되 숫자·고유명사 등을 막는 문자 제한은 두지 않는다. 공백 입력·길이·토큰 상한은 기존 안전 검사를 따른다.
- 실행 전 마지막 결과와 비교해 바뀐 설정을 표시한다. 한 번에 하나를 바꾸도록 권하고 여러 설정을 바꿨다면 그 사실을 남긴다. A 한 쌍 또는 B 한 실행 안의 고정 조건은 반드시 일치해야 한다.
- 직접 입력, A의 4프레임, B의 부분 구간은 라이브 탐색 범위다. CPU 재생에서는 정확히 일치하는 저장 결과가 없음을 표시하며 다른 결과로 대체하지 않는다.

## 3. 새 영상 준비

영상은 **소리가 나는 동작을 볼 수 있는 장면** 1개와 **환경음·화면 밖 단서를 탐색할 수 있는 장면** 1개를 추가한다. 기존 동물 영상과 대상·단서가 겹치지 않도록 한다. 화면 밖 단서가 확인되지 않은 환경 영상을 그 유형으로 단정하지 않는다.

후보가 기준에 맞지 않으면 같은 역할의 공개 재사용 가능 영상이나 직접 촬영한 영상으로 교체한다. 출처 제목·파일명은 모델 프롬프트에 넣지 않는다. 학생 드롭다운은 `장면 1 / 장면 2 / 장면 3`과 중립적인 미리보기를 제공하며, 출처는 확인할 수 있는 접힌 영역에 둔다. 저작자·라이선스·변경 내역은 영상과 함께 배포한다. 저장소 코드 라이선스를 영상에 자동 적용하지 않는다.

채택 기준은 자연스러운 소리, 관찰 가능한 단서, 수업 적합성, 재배포 가능성, 처리 가능성이다. 모델의 정답 여부나 Δ가 크다는 이유로 채택하지 않는다. 사람이 적은 시청·청취 메모는 모델 평가의 정답표와 구분해 교사용으로 보관한다. 기존 영상의 출처도 같은 목록에서 확인한다.

### 원본·무음 제작과 검증

- 새 수업 클립은 기존 소 영상과 같은 정확한 10초, 가로·세로 중 긴 변 640px 이하·짧은 변 360px 이하, 24fps 이하, 모노 16kHz, 파일당 3MiB 이하를 목표 상한으로 한다. 확대하지 않고 종횡비를 보존한다. 새 4개 파일 합계는 12MiB 이하로 한다.
- 원본 수업 클립을 한 번 정규화한 다음 그 비디오 스트림을 그대로 복사해 무음본을 만든다. 무음은 오디오 트랙 삭제가 아니라 같은 시간축의 0에 가까운 파형이다.
- 두 파일의 디코딩된 영상 프레임·타임스탬프, 오디오 샘플 수·샘플레이트·채널·시간축을 대조한다. 원본의 실제 들리는 소리와 무음본의 무음을 사람이 확인한다. 4/8프레임으로 샘플링한 시각 입력도 일치해야 한다.
- 파일 해시, 원천 파일 URL·해시, 추출 시작/종료 시각, 변환 명령·도구 버전, 검증 결과를 저장한다. 기존 `02321` 파일은 이유 없이 재인코딩하지 않는다.
- 카탈로그에 검증된 파일만 등록하고, 런타임에서도 경로·해시를 확인한다. `*_silent`라는 이름만으로 짝을 추정하지 않는다. 수업 중 외부 동영상 사이트에 연결해 재생하거나 파일을 변환할 필요가 없어야 한다.

## 4. 학생 화면과 수업 흐름

`활동 선택 → 영상 미리보기 → 바뀌는 것/고정되는 것 → 예상(선택) → 실행 또는 저장 결과 → 비교 → 관찰 기록 → 직접 바꿔 보기` 순서다.

- 예상은 `달라질 것 같다 / 비슷할 것 같다 / 아직 모르겠다`와 자유 메모다. 미작성은 실행을 막지 않는다. 영상·오디오는 자동 재생하지 않는다.
- 질문·영상·입력 초안 선택은 추론을 시작하지 않는다. 명시적인 실행 버튼만 추론을 시작한다. 결과 제목에는 마지막 실행의 실제 조건을 표시한다.
- 추천 최소 경로는 한 영상에서 A 수행 → 한국어 질문 한 번 변경 → 같은 영상에서 B 관찰 → 새 영상 한 개에 적용 → 다음 질문 기록이다. 나머지 조합은 선택 탐색으로 둔다.
- 기존 고급 폼은 유지하되 `선택 탐구 / 내부 더 살펴보기`로 뒤에 배치한다. 첫 화면에 모든 레이어·규칙·지표를 동시에 펼치지 않는다.
- 관찰 기록은 `바꾼 것 / 그대로 둔 것 / 관측한 것 / 가능한 설명 / 다음 질문`이다. supported/refuted 선택을 기본 제출의 필수 조건으로 삼지 않는다.

## 5. 실행·기록·저장 결과 계약

- 실행 시 초안을 복사해 고정한다. 재평가된 같은 클릭은 추론을 반복하지 않고, 다음 명시적 클릭은 새 요청이다. 기록·보기 셀과 추론 셀을 분리한다.
- A는 두 실제 실행, B는 기준선·차단 증거를 가진 한 실제 실행을 참조한다. 두 번째 계산 실패 시 첫 결과와 실패 조건을 보존하고 `비교 미완료`를 표시한다.
- 비교마다 `comparison_id`, 요청 ID, 활동/영상/질문 버전, 정확한 프롬프트, 제출 설정, 예상, 결과 출처, 실행 증거와 관찰 메모를 보관한다. 메모 수정은 과학적 실행 ID와 출처를 바꾸지 않는다.
- 영상 선택은 검증된 media catalog의 ID·버전·파일 해시로 추적한다. 대조 쌍 등록은 기존 `comparison_key` 계약을 사용하며 실제 두 파일 외에는 그 키를 발급하지 않는다.
- 저장 결과는 기본 8프레임·64토큰·B 전체 구간의 18개 조합을 실제 GPU에서 생성한다. 허구 수치나 예상 답변을 배포 예제로 만들지 않는다.
- 저장 결과 키는 활동·영상·질문 및 버전, 정확한 프롬프트, 파일 해시, 프레임·상한·규칙·모델 리비전을 포함한다. 헬퍼 코드 등 생성 출처도 별도로 고정한다. 다른 영상·질문 결과를 현재 결과로 표시하지 않는다.
- 저장 결과를 학생 기록으로 가져올 때 새 비교 ID를 만들고 원래 `source_example_id`와 생성 출처를 유지한다. 가져온 시각은 생성 시각과 별도로 둔다. 다시 열어도 기존 메모를 덮어쓰지 않는다.
- `CTP49906_REPLAY=1`의 CPU 세션에서는 모델 가중치·GPU 없이 18개 저장 비교의 선택·기록·내보내기가 가능해야 한다. 나머지 조건은 라이브 필요 안내를 제공한다.
- 저장 파일 누락·해시 오류·조건 불일치·잘못된 배열은 해당 결과만 사용 불가로 표시한다. 전체 묶음은 배포 전 18개가 모두 유효해야 한다.
- 기존 `run_record`, `append_run`, `matched_control_ids`, JSON의 `runs` 의미를 보존한다. 저장 결과를 새 라이브 실행으로 기록하지 않는다.

## 6. 설명과 확인

학생 안내에서는 입력이 숫자 표현으로 바뀌어 함께 처리된다는 개요만 먼저 설명한다. 한국어 질문도 모델이 항상 한국어로 답하거나 정확히 관찰함을 보장하지 않으므로 실제 출력은 번역·교정 없이 보여 준다. 질문 변경은 입력 제거가 아니며, 동일 답변은 내부 처리의 동일함을 입증하지 않는다. 어텐션 차단 결과와 로짓 렌즈도 모델의 생각 전체를 보여 주는 것으로 설명하지 않는다.

워크시트는 관찰 기록과 다음 질문을 중심으로 바꾸고 해시·커밋은 자동 첨부 부록으로 둔다. README·교사용 안내·QA에는 새 영상 출처, 18개 저장 결과의 범위, 라이브 전용 조작, 부분 실패 복구와 다운로드 절차를 맞춘다. `묶음가` 등 남은 표현도 고친다.

비전공자 3~5명의 짧은 시범 활동을 제안한다. 소리 제거와 연결 차단의 차이, 답변이 같은 경우의 해석, 다음에 바꿀 변수를 자기 말로 설명하는지 확인한다. 동일한 오해가 반복되면 안내와 순서를 수정한다. 이는 사용성 확인이며 학습 효과를 입증하는 연구가 아니다.

## 7. 전역 제약

- Python >=3.11, marimo==0.25.0, transformers==4.52.4, 모델 Qwen/Qwen2.5-Omni-3B, MODEL_REVISION=f75b40e3da2003cdd6e1829b1f420ca70797c34e.
- 기존 GPU용 torch를 UI 개선 때문에 교체하지 않는다. 새 웹 서버·터널·프런트엔드 프레임워크를 추가하지 않는다.
- `CTP49906_avllm_molab_html_kr.py`는 직접 편집하지 않고 canonical 노트북과 `scripts/build_molab_html.py`에서 생성한다.
- `src/teacher_forcing.py`와 `src/attention_knockout_experiment.py`의 측정 정의를 바꾸지 않는다. 새 실행 경로는 기존 계산 함수를 호출한다.
- 비교 사이에는 의도한 변수만 바꾼다. 프레임·프롬프트·모델·코드·상한의 숨은 변경을 허용하지 않는다.
- 한국어판의 추천 프롬프트·학생 활동은 한국어로 구성하며 영어 비교 활동을 추가하지 않는다.
- 새 영상 2종의 출처·이용 조건·원본/무음 정합성과 실제 GPU 결과를 첫 배포 완료 조건에 포함한다.
- 사용자 입력과 모델 출력은 HTML/Markdown에서 이스케이프하고 JSON에는 원문을 보존한다.
- 저장 예제를 라이브 실행으로 표시하지 않는다. 출처의 해시·시간·모델 정보를 현재 값으로 덮어쓰지 않는다.
- 예제 선택·초안 편집·관찰 기록·다운로드는 추가 추론 0회를 만족해야 한다.
- 기술 검사 통과, Molab GPU 검증, 학생 시범 활동은 각각 별도의 완료 상태로 보고한다.

## 8. 제외 범위와 게시 판정

자유 업로드의 자동 무음본 제작, 새 Studio 웹 화면, 자동 정답 평가, 모달리티 완전 제거 실험은 이번 범위에서 제외한다. 영어 비교는 한국어판의 후속 과제로도 남기지 않는다.

첫 배포는 새 영상 2종, 총 3개 영상 쌍, 두 활동, 세 한국어 질문, 18개 검증된 저장 결과, 직접 입력·관찰 기록·내보내기가 동작할 때 완료한다. GPU가 없으면 개발 검증만 완료로 기록한다. 보조 코드·영상·저장 결과 커밋을 먼저 만든 뒤 노트북 `REPO_REF`를 맞춰 생성·검증한다. 실제 학생 시범 활동의 수행 여부는 별도로 명시한다.
