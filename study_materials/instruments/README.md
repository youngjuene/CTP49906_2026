# Common classroom instruments — candidate package

**Package version:** `common-instruments/0.1.0-pilot`  
**Status:** structurally complete candidate; **not validated, not piloted, and not
approved for research use**

These files support the same administration identifiers, artifact fields, and
scoring structure across classroom surfaces. They do not assign students to a
surface, encode allocation in a student portfolio, or replace ethics, methods,
accessibility, translation, arts-education, or rater review.

## Files

| File | Purpose |
|---|---|
| `instrument_catalog.json` | Version, provenance, administration, scoring, missingness, permissions, translation, pilot, and human-gate metadata |
| `critical_ai_reasoning.en.json` | English common pre/post scenario prompts |
| `critical_ai_reasoning.ko.json` | Korean prompts with the same immutable content keys |
| `artifact_rubrics.json` | Condition-independent creative-flexibility and audiovisual-intentionality candidate rubrics |
| `rater_guide.md` | Blinded scoring, missingness, adjudication, and reliability rehearsal guide |
| `matched_route_fidelity_form.json` | Instructor-only matched-route observation/deviation form |
| `protocol_templates.md` | Teaching rehearsal, accessibility, privacy, and unresolved research-gate templates |

## Honest-use boundary

- Scores are formative candidate evidence, not validated constructs.
- `not_piloted`, `unresolved`, and `not_approved` values are intentional stop
  states; do not replace them with success labels without accountable evidence.
- Raters receive artifacts and rationales under pseudonymous record IDs. Allocation
  metadata stays with the instructor/protocol side and is excluded from student
  downloads.
- English/Korean key equality is machine-checked. Semantic equivalence, terminology,
  line expansion, and accessibility still require qualified human review.
- Two independent audience readings are the classroom minimum for comparison, not
  a research sample-size justification.
