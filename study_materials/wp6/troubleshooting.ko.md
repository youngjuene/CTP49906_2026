# 문제 해결 안내

**문서 ID:** `troubleshooting/1.0.0`

## 청중 화면

- **패킷 거부 / 필드 누락:** 창작자에게 새 패킷을 요청하세요. 직접 필드를
  추가하지 마세요.
- **체크섬 불일치:** 중단하세요. 제시 참조가 바뀌었거나 패킷이 손상되었습니다.
  검증된 창작자 흐름에서 다시 생성하세요.
- **창작자/기계/개인 필드 거부:** 의도된 개인정보 보호입니다. 허용 목록
  패킷을 다시 만들어 누출 원인을 제거하세요.
- **응답 확정 불가:** 모든 라벨 필드를 채우고 블라인드 상태를 확인하며,
  식별 정보 없는 가명을 쓰고 패킷을 공개 전 상태로 유지하세요.
- **중복 청중 또는 세션:** 실제로 독립적인 새 응답을 받으세요. 같은 사람이나
  세션의 이름만 바꿔서는 독립 응답이 되지 않습니다.
- **공개 뒤 받은 응답:** 기록된 편차로만 보존하며 두 블라인드 수에 넣지 않습니다.
- **다운로드 없음:** 초안이 검증되지 않았습니다. 표시 오류를 고쳐 다시
  제출하세요. 초안 컨트롤 편집만으로 기록이 생기지 않습니다.

## 재생과 노트북

- **GPU 없음:** 저장된 수업 재생을 선택하세요. 라이브 전용 기능은 이유와
  함께 사용할 수 없게 보여야 합니다.
- **재생 체크섬 불일치:** 사용을 중단하고
  [replay_manifest.json](replay_manifest.json)의 모든 파일과 비교하세요.
  승인된 재생성이 새 매니페스트 버전을 만들기 전에는 예상 해시를 바꾸지 마세요.
- **메타데이터 불일치:** 맞는 자극, 프레임 수, 프롬프트, 모델 revision,
  설정을 복원하거나 새 묶음을 생성하세요.
- **업로드 미디어 사전검사 실패:** 길이, 스트림, 해상도, 프레임률,
  디코딩 메모리 검사를 우회하지 말고 원본 미디어를 수정하세요.
- **내보내기 실패/중단:** 이전 기록을 보존하고 부분 파일을 제거한 뒤,
  보고된 연결/필드 문제를 고쳐 새 명령으로 다시 시도하세요.

## 접근과 언어

- 교수자 안내의 키보드 순서를 사용하세요. 포커스, 라벨, 제목, 상태 안내
  누락은 배포 차단 결함으로 보고합니다.
- 시각 자료를 사용할 수 없으면 [visual_alternatives.json](visual_alternatives.json)과
  다운로드 데이터를 사용하세요.
- 영문과 한글의 의미가 다르면 해당 언어 경로를 중단하고 번역 차이를
  기록하세요. 자동 키 일치는 자격 있는 번역 검토가 아닙니다.

이 자료는 research-ready가 아닙니다. 거버넌스, 접근성, 현지화, 청중,
도구 문제는 승인을 임의로 만들지 말고 담당 교수자나 사람 검토자에게 문의하세요.
