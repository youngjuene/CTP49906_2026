# 학생 빠른 시작

**문서 ID:** `student-quick-start/1.0.0`

1. 교사가 라이브 GPU 경로를 준비하지 않았다면 **저장된 수업 재생**을
   선택하세요. 저장 재생은 수업 예시이며 여러분의 연구 근거가 아닙니다.
2. 제목 순서대로 진행하세요: 안내, 계획, V1 등록, 관찰, 한 번의 실험,
   읽기 비교, V2 수정, 내보내기.
3. 모델 실행 전에는 예측을 확정하고, 실행 후에는 관찰, 해석, 한계,
   경쟁 설명, 다음 대조군을 기록하세요.
4. 청중에게 공유할 때는 검증된 블라인드 패킷만 다운로드하세요. 패킷에는
   창작 의도, 기계 출력, 조건, 개인 ID, 콘텐츠 해시가 없습니다.
5. 청중은 별도 GPU 없는 화면에서 패킷을 검증하고 독립적으로 응답한 뒤
   읽기 JSON 하나를 다운로드합니다.
6. 청중 가명과 세션 가명이 서로 다른 응답 두 개를 가져오세요. 두 파일이
   모두 유효할 때까지 창작자와 기계 읽기는 숨겨집니다.
7. 사람이나 기계 답을 정답으로 서열화하지 말고 읽기를 비교하세요. 현재
   자료가 담지 못한 또 다른 읽기도 적으세요.
8. 검증 상태가 유효할 때만 개인 포트폴리오를 다운로드하세요.

## 데이터 경계

업로드와 기록은 여러분의 기기 안에서만이 아니라 호스팅된 노트북
세션/컨테이너에서도 처리됩니다. 작품, 과정 기록, 청중 응답은 교수자에게
자동 전송되지 않습니다. 다운로드 컨트롤을 눌렀을 때만 파일이 만들어집니다.
플랫폼 보존 정책은 교수자에게 확인하세요.

자막, 전사, 설명은 사람이 수정할 수 있는 접근 지원입니다. 이 내용은
몰래 모델 입력으로 바뀌지 않습니다. 차트를 사용하기 어렵다면 텍스트
대안이나 다운로드 가능한 데이터 표를 사용하세요.

이 수업 경로는 research-ready가 아니며 수업 활동 참여가 연구 동의는 아닙니다.
