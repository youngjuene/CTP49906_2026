# 개인정보 및 데이터 사전

**문서 ID:** `privacy-data-dictionary/1.0.0`  
**기본 모드:** 수업

## 경계와 권한

수업 모드는 실패 시 안전하게 닫힙니다. 연구 배정, 연구 목적지, 연구
내보내기를 표시하지 않습니다. 과정 데이터 분석, 수업/청중 공유, 인용·복제,
향후 재사용 권한은 서로 독립적이며 하나가 다른 권한을 뜻하지 않습니다.

노트북은 학생 미디어나 기록을 자동 전송하지 않습니다. 학생 데이터 이동은
사용자가 시작한 개인 다운로드, 권한이 유효한 블라인드 청중 패킷, 또는
별도 승인 뒤의 최소화 연구 투영으로 제한됩니다. 패키지·저장소·모델 읽기는
서비스 입력이며 학생 데이터를 전송할 권한이 아닙니다.

## 핵심 청중 필드

| 필드 | 의미 | 개인정보 규칙 |
|---|---|---|
| `exchange_artifact_id` | 제시 패킷과 읽기를 연결하는 불투명 ID | 콘텐츠 해시, 파일명, 경로, 개인 작품 ID를 재사용하지 않습니다. |
| `presentation_asset` | 허용된 참조, 미디어 유형, 길이, 선택적 접근 지원 참조 | 원시 미디어나 창작자/기계 필드를 넣지 않습니다. |
| `presentation_checksum` | 정규화한 제시 참조의 SHA-256 | 변경을 찾지만 진실, 저자, 권한, 소유권을 증명하지 않습니다. |
| `sharing_permission_scope` | 독립적인 수업/청중 공유 권한 | 패킷 내보내기 전에 유효해야 합니다. |
| `response_id` | 안정적인 읽기 기록 ID | 한 교환 안에서 고유해야 합니다. |
| `audience_pseudonym` | 수업 가명 | 익명이 아니라 가명 처리입니다. |
| `respondent_session_pseudonym` | 반복 응답을 찾는 별도 세션 ID | 이름, 이메일, 경로, 기기 ID가 아니어야 합니다. |
| `local_created_at_utc` | 개인/수업 읽기에 남는 시각 | 최소화 연구 투영에는 허용되지 않습니다. |
| `open_interpretation` | 응답자 자신의 읽기 | 원문을 보존하며 자동 답변으로 대체하지 않습니다. |
| `accessibility_barriers` | 장벽 보고 또는 “응답하지 않음” | 민감한 자유 텍스트로 취급하고 승인 경로에서만 공유합니다. |
| `blindness_attestation` | 금지된 정보를 보지 않았는지 | 거짓이거나 공개 뒤 받은 응답은 유효 블라인드 수에 포함하지 않습니다. |
| `withdrawn` | 추가 전용 철회 상태 | 철회가 이전 바이트를 다시 쓰지 않습니다. |

블라인드 패킷에는 창작 의도, 모델 출력, 조건 배정, 개인 ID/해시,
승인되지 않은 원시 미디어가 없습니다. 공개 상태는 되돌릴 수 없습니다.
같은 교환의 서로 다른 유효 블라인드 응답 두 개가 검증된 뒤에만
창작자/기계 비교를 만들 수 있습니다.

기관 보존·삭제·사고 대응·국외 처리·승인 연구 목적지는 사람이 결정할
거버넌스 항목입니다. 이 사전은 research-ready 승인이 아닙니다.
