# 워크시트 전환 안내

**문서 ID:** `worksheet-migration/1.0.0`

기존 이중언어 `avllm_interpretability/WORKSHEET.md`는 실행마다 자유 형식
한 줄을 저장했습니다. 현재 노트북은 이를 불변 실행 ID에 연결된
**준비 → 실행 → 성찰** 확정 기록으로 대체합니다.

| 기존 필드 | 현재 기록 | 전환 규칙 |
|---|---|---|
| 설정 | 준비된 실행 입력 | 정확한 클립/자극, 프롬프트, 조건, 측정, 매개변수를 옮깁니다. |
| ▶ 전 가설 | 예측 | 실행 전에 작성한 경우만 옮기고, 아니면 누락으로 표시합니다. |
| 결과 | 확정 결과 | 기록된 값과 출처를 실행 ID에 연결하며 추정값을 다시 쓰지 않습니다. |
| 판정 | 성찰 | 관찰, 해석, 한계, 경쟁 설명, 다음 대조군을 구분합니다. |
| 대조군 질문 | 다음 대조군 필드 | 통과와 실패가 각각 무엇을 뜻하는지 씁니다. |

기록되지 않은 시각, 명령 ID, 출처, 예측을 사후에 채우지 마세요. 기존
워크시트는 수업 메모로 보존하고 연구 기록으로 변환하지 않습니다. 새
활동은 노트북의 버전 있는 폼에서 시작하세요.

워크시트의 청중 코멘트는 유효한 가져오기 파일이 아닙니다. 블라인드
청중 읽기 JSON 스키마를 사용하고 원래 다운로드 파일을 보존하세요.
